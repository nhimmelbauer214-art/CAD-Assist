Ein Konstrukteur, keine Agentur

CAD-Assist ist ein Start-up von einem Konstrukteur — kein Team, kein Callcenter. Sie schreiben direkt mit mir.

Als Ein-Mann-Start-up nehme ich aktuell bewusst nur wenige Projekte gleichzeitig an: jede Skizze bekommt die Zeit, die sie braucht, statt in einer Warteschlange zu verschwinden.

Häufige Fragen

FAQ
// PREIS

Was kostet das?

Jedes Projekt ist anders. Deshalb gibt es keine Pauschalpreise — schicken Sie mir Ihre Idee, und Sie erhalten ein unverbindliches, ehrliches Angebot.

// DAUER

Wie lange dauert es?

Ich arbeite aktuell nebenberuflich an CAD-Assist. Rückmeldung auf Ihre Anfrage erhalten Sie innerhalb von 2–3 Werktagen, die Umsetzung dauert je nach Projekt meist 1–2 Wochen.

// KAPAZITÄT

Nimmst du aktuell Projekte an?

Ja, aber bewusst nur wenige gleichzeitig. Ist meine Kapazität ausgeschöpft, sage ich Ihnen das ehrlich und nenne Ihnen einen realistischen Starttermin.

// VERSAND

Wie schicke ich mein Teil?

Gut verpackt per Post an mich. Nach dem Vermessen bekommen Sie Ihr Original zurück — die genaue Adresse erhalten Sie nach der ersten Rückmeldung.

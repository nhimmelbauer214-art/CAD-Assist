# CAD-Assist

This repository contains CAD-Assist — utilities and helpers for CAD workflows.

This project now includes a basic GitHub Pages site in the `docs/` folder. To publish the site:

1. Go to the repository Settings → Pages.
2. Under "Source", select the `main` branch and the `/docs` folder, then save.
3. After a minute the site will be published at `https://nhimmelbauer214-art.github.io/CAD-Assist/` (or a similar URL shown in the Pages settings).

If you'd like a different design, a Jekyll site, or an automated Pages deploy workflow, tell me which you prefer and I'll add it.

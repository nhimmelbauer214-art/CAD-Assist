CAD-Assist

CAD Company — assistive tools for designers and engineers

About

CAD-Assist is a project to provide utilities and helpers for CAD workflows. This site is a simple project homepage that points to the repository and contains quick start instructions.

Quick start

  1. Clone the repository: git clone https://github.com/nhimmelbauer214-art/CAD-Assist.git
  2. Open the project in your preferred CAD or development tools.

Documentation

Documentation and examples can be added to this site as Markdown files converted by Jekyll, or as additional HTML files inside the docs/ folder.
